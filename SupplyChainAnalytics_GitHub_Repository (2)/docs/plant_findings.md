**Plant findings**

**What we wanted to know**

Which plants handled the most order records and quantity?

**What the results showed**

- PLANT03 had 8,541 order records.
- PLANT12 had 300 order records.
- PLANT16 had 173 order records.
- PLANT08 had 102 order records.
- PLANT13 had 86 order records.
- PLANT09 had 12 order records.
- PLANT04 had 1 order record.
- PLANT03 contributed 96.94% of the total recorded quantity.
- Twelve plants in the 19-plant list had no matching order records.

**What this means**

Most of the recorded order activity was linked to PLANT03. It is the main plant in this dataset by order count and quantity.

**What this does not tell us**

This does not prove that PLANT03 used 96.94% of its capacity. Order quantity and daily plant capacity are different measures. The time period must also be considered before calculating capacity use.
